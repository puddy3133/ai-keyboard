## 安全与配置边界

- 麦克风控制 wire 当前为 v1，只限制来源 IP 必须与已配置 `audio_host` 的解析地址一致；预留 token 不做密码学验证，也不防重放。
- 同一已配置主机地址可以向 Wi-Fi 控制端口发送配置 JSON；该能力只适合受信任本地网络，不应暴露到互联网或不可信局域网。
- Wi-Fi 凭据与同步密钥可以经既有配置通道提供；仓库不保存任何真实值。
- 仓库不保存真实凭据、设备标识或部署配置；公开测试中的固定值只是测试向量。
- 固件仓库不包含桌面 companion 应用，因此麦克风上行的端到端体验需要另行连接兼容实现。

## 发布判据

当前默认固件已在 EasyInput V2.0 实板完成联合功能测试，主流程观察正常。该结论对应当前公开候选和当前实板，不替代 IMA-ADPCM、Ogg/Opus 等独立诊断构建，也不自动扩展为所有电脑、网络环境、硬件批次和破坏性故障场景均已验证。
