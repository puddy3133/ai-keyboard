# EasyInput Maker 首个公开版本范围

## 1. 项目定位

EasyInput Maker 是面向 EasyInput V2.0 的社区固件，服务于个人学习、研究、教学实验和非商业 Maker 共创。使用者应当能够下载、构建、烧录，并借助 AI 修改已有功能或增加新功能。

项目以源码公开可见、禁止未经授权商业使用的方式发布。如需商业使用，请通过 WaytoAGI 社区或原作者 CY-CHENYUE 提交授权申请；最终授权以相关版权方或其书面授权代表确认为准。正式发布时，以仓库根目录的许可证正文和第三方声明为准。

## 2. 目标硬件

以下名称表示同一块当前硬件基线：

- 对外名称：EasyInput V2.0；
- 固件板型别名：`v2`；
- PCB 丝印：AI Keyboard V2.1。

硬件使用 ESP32-S3R8、8 MB PSRAM 和 16 MB Flash。固件不得因为名称差异把它们当成不同电气板型。

## 3. 首版能力范围

首个公开版本以“完整保留经确认的固件功能，同时便于学习者扩展”为目标。公开版不是另做一套精简教学固件；只要某项功能的源码和必要依赖具备公开权利，就应当纳入并保持设备身份、配置格式、通信协议和运行行为兼容。公开仓库可以增加许可、贡献、测试与教学资料，但不自行改写固件功能基线。

| 能力 | 首版要求 |
| --- | --- |
| 主输入 | 支持 S1-S8 独立按键与多键检测；具体业务动作由公开固件定义，不属于板级事实 |
| 旋钮 | 支持编码器 A/B 正交相位和按压；方向、步进与交互允许社区扩展 |
| 灯光 | 支持 5 颗串联 WS2812 和独立状态灯；亮度、颜色、动画和状态语义可修改 |
| USB 与蓝牙 | 提供经过验证的基础 HID 能力；设备身份和上层行为由项目定义 |
| 配置与状态 | 支持公开、可理解的本地配置与状态能力，不携带真实账号、网络凭据或设备私有数据 |
| 电池与功耗 | 支持供电检测、电池电压采样以及经过验证的睡眠/唤醒策略 |
| 麦克风与扬声器 | 完整保留板载麦克风采集、Wi-Fi UDP 上行、扬声器播放、声音资源管理及其存储与传输能力；不公开真实凭据，音频素材必须单独确认再发布权 |
| 网络扩展 | 保留当前兼容 wire；明确记录其信任模型与限制，未经整体兼容设计不单方面替换协议 |

## 4. 必须遵守的板级合同

- S1-S8 固定为 GPIO `2, 47, 38, 41, 1, 6, 7, 48`，均为低有效独立输入；GPIO0 不是产品按键。
- 编码器 A/B/按压固定为 GPIO `17/16/18`；A/B 是正交相位，不能按普通长按键处理。
- GPIO8 是 LED、麦克风和扬声器的高有效共享电源域，不是单独的灯光开关。所有消费者停止并恢复安全引脚状态后才能关断。
- 5 颗 WS2812 串联使用 GPIO12；原生 USB 使用 GPIO19/20。
- 麦克风使用 GPIO9/10/11，扬声器使用 GPIO14/13/15；GPIO11 是输入，在外设掉电时保持浮空。
- KEY_WAKE/GPIO21 只能表示存在输入唤醒，唤醒后必须重扫独立输入才能确定来源。
- 进入下载模式：开发板开机状态下短按并松开一次 BOOT。退出下载模式：关机后重新开机。不得要求按住 BOOT、配合重新上电或寻找不存在的 RESET 键。
- GPIO8 拉高后的通用最短稳定时间目前没有充分证据。任何具体时间都必须由所选器件配置或实板测量验证，不能宣称为板级固定值。

## 5. 可以纳入公开仓库的内容

- ESP-IDF 构建入口、板级适配、应用源码和必要组件；
- 支持首版能力所需的公开功能模块；
- 可在普通电脑运行的单元测试、协议测试和静态检查；
- 可复现构建所需的依赖声明与锁定文件；
- 经过审核的分区与默认配置；
- 面向使用者的构建、烧录、恢复、扩展和故障排查文档；
- 面向 AI/Vibe Coding 的公开项目入口、贡献说明与社区协作文件；
- 权属清楚、允许随项目再发布的示例素材。

## 6. 默认不纳入的内容

- 构建产物、缓存、临时文件、编辑器索引和本机配置；
- 固件二进制、调试符号、内存映射、崩溃转储和未经整理的运行日志；
- 账号、密钥、口令、网络凭据、设备唯一标识、个人信息和真实环境配置；
- 制造、售后或运维资料；
- 完整原理图、PCB 制造资料、BOM、Gerber、贴片与装配文件，除非以后经过单独授权；
- 权属不清或没有再发布许可的代码、音频、图片、字体和其他素材；
- 历史备份、旧版本归档和与当前公开版本无关的诊断工具；
- 与固件使用、贡献或可复现验证无关的过程记录。

## 7. 整改后才能纳入的内容

| 类别 | 发布前要求 |
| --- | --- |
| 远程控制 | 如实记录当前来源 IP 限制、预留 token 未认证和配置 JSON 入口；只允许受信任本地网络使用，不夸大其安全能力 |
| 配置存储 | 默认值不得含真实凭据；明确清除、恢复与升级行为；敏感信息的保存和日志策略经过审查 |
| 音频与网络素材 | 确认版权与再发布权；没有证据时改用自制或明确允许再发布的素材 |
| 第三方组件 | 保留原许可证和版权声明，并写入第三方通知；不得把第三方代码错误标成项目自有非商业代码 |
| 硬件文档 | 使用当前板级事实；禁止传播错误 BOOT 流程、错误 GPIO 和未经证实的时序参数 |
| 协作与工具配置 | 仅保留对公开贡献确有帮助、没有本机路径或私有信息的内容 |

## 8. 发布门槛

首个公开版本只有同时满足以下条件才能发布：

1. 自有代码许可证、第三方通知和素材授权完整；
2. 敏感信息与隐私扫描没有未处理发现；
3. 远程控制、配置入口与已知安全边界记录准确，README 不把来源 IP 限制描述为密码学认证；
4. 板型、引脚、方向、电平和 GPIO8 生命周期符合当前硬件合同；
5. 从干净环境可以解析锁定依赖并完成 ESP-IDF 构建；
6. 自动测试通过，并记录测试实际覆盖范围；
7. 在 EasyInput V2.0 实板验证烧录、输入、灯光、USB/BLE、音频、电源和恢复流程；
8. README 不硬编码个人串口路径，BOOT 操作与当前实板一致；
9. 所有纳入 Git 的文字、代码、提交信息和素材均确认适合长期公开。
10. 功能等价清单中不存在没有公开原因和替代方案的缺失项；脱敏只替换敏感输入，不删除对应功能链路。

静态扫描通过、构建通过和实板功能通过是不同证据，不能互相替代。
