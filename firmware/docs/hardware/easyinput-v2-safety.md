# EasyInput V2.0 硬件安全边界

本文只记录公开固件开发必须遵守的当前板级事实。产品名 EasyInput V2.0、固件别名 `v2` 和 PCB 丝印 AI Keyboard V2.1 表示同一块硬件基线。

## 已确认的主要引脚

| 功能 | GPIO / 约束 |
| --- | --- |
| S1–S8 | `2, 47, 38, 41, 1, 6, 7, 48`，低有效独立输入 |
| 编码器 A / B / 按压 | `17 / 16 / 18`；A/B 是正交相位 |
| WS2812 | 数据 GPIO12，5 颗串联 |
| 原生 USB | D− GPIO19，D+ GPIO20 |
| BOOT | GPIO0；不是产品按键 |
| 输入唤醒 | KEY_WAKE / GPIO21；唤醒后必须重扫独立输入 |
| 外设共电 | GPIO8，高有效，LED / 麦克风 / 扬声器共享 |
| 麦克风 I2S | BCLK / WS / DATA IN = `9 / 10 / 11` |
| 扬声器 I2S | BCLK / WS / DATA OUT = `14 / 13 / 15` |

代码中的当前声明以 `components/keyboard/include/keyboard/board_pins.h` 为入口。改动引脚常量不是普通业务配置，必须有硬件证据和维护者复核。

## GPIO8 不是灯光开关

GPIO8 同时给 LED、麦克风和扬声器供电。只想“调暗灯光”时，应缩放 WS2812 的 RGB 数值，不应反复拉低 GPIO8；否则可能在录音或扬声器工作时切断整个外设电源域。

关闭 GPIO8 前必须满足：

1. LED、麦克风和扬声器消费者都已停止；
2. 相关控制器已停用或释放；
3. 输出引脚恢复为安全状态；
4. GPIO11 作为麦克风输入，在外设掉电时保持输入/浮空；
5. 共享资源的所有权和并发状态已收敛。

GPIO8 拉高后的通用最短稳定时间目前没有充分板级证据。代码中的等待只能被描述为当前实现策略，不能写成所有器件配置都适用的硬件固定参数；新的时序结论需要数据手册或实板测量。

## BOOT 与下载模式

- 正常使用时 GPIO0 不是第 9 个按键；
- 自动烧录失败后，开发板开机状态下短按并松开一次 BOOT，可进入下载模式；
- 已经进入下载模式后不要重复按 BOOT；
- 手动进入后要恢复正常启动：关机，再重新开机；
- 不使用“按住 BOOT + 上电”的流程，也不假设存在 RESET 键。

## 什么证据能证明什么

| 证据 | 能证明 | 不能证明 |
| --- | --- | --- |
| 常量/静态扫描 | 声明与已知合同是否一致 | 电气行为和实物效果 |
| 宿主测试 | 与硬件无关的逻辑和失败边界 | GPIO、射频、音频质量 |
| ESP-IDF build | 代码和依赖可生成固件 | 固件已写入或已运行 |
| flash 成功 | 数据已写入目标 | 应用进入正常启动、功能正确 |
| 实板观察与有界日志 | 本次板、本次版本的实际行为 | 未测试环境的普遍结论 |

提交涉及 GPIO0、GPIO8、GPIO11、GPIO19/20、音频控制器、睡眠或供电顺序的改动时，必须明确列出已运行和未运行的验证。
